FDC Console MJ — La Nuit des Morts-Vivants (PWA V3)

1. Ouvrir https://app.netlify.com/drop
2. Déposer le DOSSIER FDC_Console_MJ_PWA_Nuit_V3 extrait du ZIP.
3. Ouvrir l'adresse HTTPS fournie sur Chrome Android.
4. Menu Chrome (⋮) > Installer l'application / Ajouter à l'écran d'accueil.
5. Pour les mises à jour, remplacer les fichiers du MÊME site Netlify. L'adresse ne change pas.

La note du Pet de Liche (+5 PV temporaires) et le portrait du groupe sont intégrés.
Les images et musiques déjà fournies sont conservées.
Le contenu modifié depuis l'interface est stocké localement sur chaque appareil.
Il n'y a PAS encore de synchronisation automatique ChatGPT -> hébergement :
une nouvelle version doit être publiée sur le même site.
Le bouton Google Drive exige une configuration OAuth HTTPS.
Attention : l'hébergement statique Netlify rend les assets accessibles à toute personne
disposant de leur URL ; ne pas y publier de contenu confidentiel.
